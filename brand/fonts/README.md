# FlutterChicha

FlutterChicha es la fuente chicha propia de FlutterConf Perú, dibujada a partir del alfabeto pintado a mano. Viene en 5 archivos TTF, uno por capa, para instalar en Canva, Figma, Keynote o en la computadora.

| Archivo | Capa | Color |
| --- | --- | --- |
| FlutterChichaSombra-Regular.ttf | Sombra (abajo de todo) | `fc-azul` |
| FlutterChicha-Regular.ttf | Letra completa | `fc-blanco` |
| FlutterChichaAmarillo-Regular.ttf | Franja del medio | `fc-amarillo` |
| FlutterChichaNaranja-Regular.ttf | Franja de abajo | `fc-naranja` |
| FlutterChichaBrillo-Regular.ttf | Brillos (arriba de todo) | blanco al 80 % |

Apila las capas en ese orden, con el mismo texto, tamaño y posición. Para web usa las versiones WOFF2 de `fonts/`. Los derechos del dibujo son de FlutterConf Perú.
